Run everything from there with the $DL shortcut below.

set DL $HOME/Downloads/"Red and Blue"/"Zip Files"

1) Refresh sources + push (clones the repo first if needed):
   test -d $HOME/aegis-repo/.git; or git clone https://github.com/jackbashroot-boop/AEGIS-Desktop.git $HOME/aegis-repo
   unzip -o "$DL/aegis-repo-upload.zip" -d /tmp/aegis-new
   cp -r /tmp/aegis-new/aegis-repo/. $HOME/aegis-repo/
   cd $HOME/aegis-repo
   git config user.name "jackbashroot-boop"
   git config user.email "jackbashroot-boop@users.noreply.github.com"
   git add -A
   git commit -m "Suite v1.2.3 - Companion 1.7.4 Settings/Dashboard scroll fix (close/single-instance/uninstall fixes, repo updater, PHOENIX 0.9.9, BENCH/LANTERN 0.1.3, HERALD 0.1.5)"
   git push

   (The git config lines fix "Author identity unknown". They are
   LOCAL to this repo - never share any password/token instead.)

2) Publish the release the Companion updater reads:
   unzip -o "$DL/Aegis-Release-v1.2.3-Assets.zip" -d "$DL/release-v1.2.3"
   gh release create v1.2.3 "$DL"/release-v1.2.3/* --title "AEGIS Suite v1.2.3" --notes "Settings scroll fix; close/uninstall fixes; repo updater; PHOENIX auto-join."
   gh release upload v1.2.1 "$DL/AEGIS-KEEP-ARCHIVE-v1.2.3.zip"   # optional restore-everything archive

3) Visibility: Companion checks releases/latest/download/latest.json
   anonymously. PRIVATE repo = 404 = no updates. Either make the
   repo public, or paste a read-only GitHub token into Companion >
   Settings > Updates & removal (stored only in your local config).

4) Verify: reboot Companion - Dashboard health should show
   "Updates ... checked against the repo", and Settings > Check
   for updates should say you are up to date on v1.7.4.
